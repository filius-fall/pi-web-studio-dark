# Contributing

Studio Dark is a free community project. Bug reports, accessibility fixes,
screenshots using demonstration data, and improvements are welcome.

Use the existing Pi Web callbacks for behavior changes and scope presentation
changes to this theme. Test desktop and phone layouts when changing controls.
State the Pi Web version used for validation. There is no dependency install
or build step for the browser plugin.

Contribute only code or assets you have the right to share. Original code
contributions are offered under this repository's MIT license. Third-party
assets keep their own licenses; they are not automatically relicensed as MIT.

For copied or adapted assets, record the original source, revision or version,
copyright notice, license, and any modifications in `THIRD_PARTY_NOTICES.md`.
Include the full required license and notice text and update
`docs/asset-provenance.json` when bundled asset files change.

Keep provider marks limited to identifying the relevant models or services.
Do not imply endorsement or use them as this project's branding. Follow the
owners' applicable trademark guidelines in addition to the asset license.
Do not commit private conversations, credentials, personal paths, or reference
screenshots from other applications as demonstration content.

If you identify an attribution or rights concern, open a repository issue
with the affected file, rights holder, source, and supporting terms so it can
be reviewed and corrected.
